# Nexus Strategy 使用教程

本文档介绍 Nexus Strategy（交易策略回测系统）的安装与回测使用方法。

## 1. 安装与启动

```bash
# 安装依赖（建议先创建虚拟环境）
pip install -r requirements.txt

# 可选：配置默认界面语言
cp .env.example .env

# 生成示例 K 线数据（可选）
python scripts/gen_sample_data.py

# 启动程序
python main.py
```

启动后进入策略回测页，菜单栏「语言 / Language」可在运行时切换中英文。默认界面语言可在 `.env` 中通过 `UI_LANGUAGE` 配置（`zh_CN` 或 `en_US`，简写 `zh` / `en` 亦可，缺省为中文）。

### 1.1 打包 Windows 可执行文件

在 Windows 命令提示符中执行：

```bat
pip install -r requirements.txt
scripts\build_exe.bat
```

默认输出为 `dist\NexusStrategy.exe`。Python 运行时、PyQt5/Qt 插件、openpyxl、python-dotenv 及其递归依赖均打包在程序中，目标电脑无需安装 Python。使用 `--console` 可保留调试控制台，使用 `--onedir` 可生成目录形式。由于 PyInstaller 不支持跨平台生成 Windows EXE，请务必在 Windows 环境运行打包脚本。打包后的 `.env` 和 `logs` 均位于 EXE 所在目录。

## 2. 回测页

### 2.1 导入数据

点击「选择文件」导入 K 线数据，支持 `.csv` 和 `.xlsx`：

- 有表头：自动识别 `open_time/open/high/low/close/volume` 或对应中文列名
- 无表头：按 `时间,开,高,低,收,量` 顺序解析

可先用 `python scripts/gen_sample_data.py` 生成 `data/sample_1m.csv` 试用。

### 2.2 配置策略参数

左侧提供 6 个可启用条件。当前 K 线收盘后确认信号，上涨信号做多、下跌信号做空；全部启用条件通过后，市价单在下一根 K 线开盘成交（仍受右侧「交易方向」限制）：

- **成交量**：当前 K 线成交量必须大于等于前 A 根 K 线（不含当前）的平均成交量 × B。
- **当前收盘相对上根绝对涨跌幅(%)**：按 `(当前收盘-上一收盘)/上一收盘×100` 计算，绝对值严格大于 C 且严格小于 D；正值做多，负值做空。
- **最少连续同向 K 线**：包含信号 K 线；0 或 1 表示忽略，N≥2 时要求最近 N 根全部与信号同向。收盘等于开盘也满足同向。
- **追涨追跌过滤**：当前收盘与前 E 根 K 线的收盘比较，同方向累计幅度严格小于 F% 才通过；反方向变化直接通过。第 E 根信号 K 线没有更早收盘可用时，与第一根 K 线开盘比较。
- **前 14 根 ATR 波动率(%) 区间**：先按 `max(高-低, |高-前收|, |低-前收|)` 求 TR，再计算信号 K 线之前 14 根 TR 的均值。用 `ATR(14)/信号前一根收盘×100` 判断范围，信号 K 线不参与 ATR。
- **逆势影线/实体过滤**：做多只检查上影线，做空只检查下影线，`逆势影线/实体` 严格小于 H 时通过；实体为 0 时不通过。

「导出参数 / 导入参数」按钮可将全部参数保存为 JSON 或从 JSON 恢复。

### 2.3 配置开单参数

- **仓位大小 / 手续费率**：每笔初始名义本金与手续费百分比。
- **止盈止损 / 最小止盈 / 止损冷静期**：止盈、止损按最新持仓均价的百分比计算，0 表示关闭对应条件；止损后 N 根 K 线内不再开仓。开仓当根 K 线也会检查止盈止损。
- **开仓时机**：所有条件在信号 K 线收盘后确认，只在下一根连续 K 线的开盘价开仓；若两根 K 线之间存在数据缺口则取消该信号。
- **交易方向**：`0` 多空都做、`1` 只做多、`2` 只做空。不符合所选方向的信号直接忽略，并继续寻找允许方向的信号。
- **加仓**：价格相对当前持仓均价反向波动达到「加仓间隔(%)」时触发。间隔或金额倍数为 0 时不加仓；倍数 1 表示每次加仓金额与初始开仓金额相同。总仓次数包含初始开仓，0/1 均表示不加仓，2 表示初始开仓后最多再加一仓。
- **同 K 线执行优先级**：同一根 K 线同时触发多个条件时，依次执行 `加仓 → 止损 → 止盈`；加仓后止盈止损以更新后的持仓均价计算。
- **最长持仓(K线)**：入场 K 线计为第 1 根，达到设置的持仓 K 线数且仍未止盈止损时，按当根收盘价强制平仓；0 表示不限制。
- **数据连续性**：引擎根据数据中最常见的 K 线时间间隔检查连续性。成交量、连续 K、累计涨跌和 ATR 的历史窗口均不得跨越缺失或重复 K 线。

### 2.4 运行与查看结果

点击「开始回测」（运行中再次点击可取消）。完成后：

- **回测结果**：总交易笔数、总盈亏、总手续费、做多/做空笔数、最大区间亏损值及区间 (#i-#j)
- **交易明细**：逐笔列出类型（止盈/止损/超时/数据结束）、方向、开平仓 K 线序号与价格、盈亏、手续费，可「导出交易明细」为 CSV
- **回测日志**：支持关键词搜索、「仅显示触发交易」过滤、分页浏览与导出

## 3. 日志文件

应用运行日志写入 `logs/trade.log`（RotatingFileHandler，单文件 5MB，最多保留 5 份），包含数据加载与回测结果记录。

每次启动回测还会生成独立文件 `logs/backtest_YYYYMMDD_HHMMSS_ffffff.log`。每根 K 线占一行，例如：

```text
K线 #3 | 2026-02-27T08:02:00.000000000 | 收盘价: 67409.80 | 成交量:34.946 | 趋势策略: ✗ | 形态策略: ✗ | 反转策略: ✗ | 成交比策略: ✗
```

其中趋势策略汇总单根涨跌、连续 K 线和累计涨跌；形态策略表示逆势影线过滤；反转策略表示信号前 ATR 过滤；成交比策略表示成交量条件。

Backtest Log 与独立日志文件均使用回测启动时的界面语言。英文界面会输出 `K-line / Close / Volume / Trend Strategy` 等英文日志字段；回测过程中切换语言不会造成单个日志文件中英文混排，新语言在下一次回测生效。

## 4. 常见问题

- **启动报错 `ModuleNotFoundError: PyQt5`**：未安装依赖，执行 `pip install -r requirements.txt`
- **导入数据失败**：检查 CSV 列顺序是否为 `时间,开,高,低,收,量`，或表头是否为受支持的列名
