14. 增加「TP / SL / TIME 当根K线是否参与信号判断」参数
在「策略参数设置」中增加一个可选项：
TP / SL / TIME 当根K线是否作为信号K线
用于控制持仓在某根K线盘中触发 TP / SL / TIME 平仓以后，这根K线完整收盘时是否继续参与新信号判断。
可设置为：
•	开启： TP / SL / TIME 所在的当根K线完整收盘后，正常判断是否满足新信号条件；如果满足，则最早在下一根K线开盘时进入新仓。
•	关闭： TP / SL / TIME 所在的当根K线不参与新信号判断，直接忽略，从下一根完整K线开始重新判断信号。
这样可以由参数自行选择两种策略逻辑。

15. 「账户总余额」根据账户仓位历史计算
「账户总余额」的更新需要根据交易所账户的 真实仓位历史 / 已实现盈亏记录 进行计算。
每完成一笔交易后，程序从账户仓位历史中找到本次已经完全结束的交易，并读取该笔交易最终的 实际已实现盈亏。
然后更新：
新的账户总余额 = 上一次账户总余额 + 本次交易实际已实现盈亏
例如：
上一次账户总余额：
10000
在仓位历史中读取到本次交易实际已实现盈亏：
+1000
则新的账户总余额：
11000
下一笔交易按照：
11000 ÷ 拆分份数 × 杠杆倍数
计算新的下单金额。
需要注意：
•	总余额的盈亏数据以 交易所账户真实仓位历史 为准；
•	不根据当前「钱包余额」或「可用资金」反推策略总余额；
•	每一笔已经结束的交易只能累计一次，避免重复计算；
•	TP / SL / TIME 等不同平仓方式都需要正确读取对应的最终已实现盈亏。

18. 实时策略日志滚动逻辑修改
目前「实时策略日志」存在一个问题：
查看日志时，界面大约每分钟刷新一次，并且会自动跳回最上方第一条数据，导致查看历史日志非常不方便。
需要修改日志右侧滚动条的自动刷新逻辑。
情况一：滚动条停留在最下方
代表正在查看最新日志。
此时有新的日志产生后：
自动向下滚动，始终显示最新日志。
情况二：滚动条已经向上移动，停留在中间位置
代表正在查看之前的历史日志。
此时即使后台产生新的日志：
界面也不要自动跳动，不要改变当前查看位置。
直到我自己重新把滚动条拉到最下方以后，再恢复自动跟随最新日志。
核心逻辑：
在底部 → 自动跟随最新日志。
不在底部 → 保持当前位置，不自动刷新滚动位置。
同时取消目前每次更新后自动跳转到第一条日志的情况。

19. 参数设置自动保存并恢复上次配置
软件中的「参数设置」需要增加自动保存功能。
每次修改参数以后，程序保存当前配置。
关闭软件以后再次打开时：
所有参数默认恢复为上一次关闭软件时使用的数值。
不需要每次启动软件重新填写。
包括策略相关参数、资金参数以及其他需要手工设置的参数，都尽量保存上一次的设置状态。
例如：
上一次关闭软件时设置：
•	K线周期：1H
•	总资金：10000
•	拆分份数：10
•	杠杆倍数：5
•	TP / SL / TIME 当根K线参与信号判断：开启
那么下次重新打开软件时，应自动恢复以上参数。
核心要求：
软件重启后，参数保持上一次关闭时的设置，不恢复成默认初始值。
